4. Core Engineering Deep-Dive

1. Zero-Polling Real-Time Gmail Watch Leverages Google Cloud Pub/Sub with the official users.watch API in googlePubSubWebhookService.ts. Eliminates polling delays, battery drain, and rate-limit hits.
2. Token Resiliency & Auto-Rotation In GoogleProvider.ts, access tokens are checked on every request. If within 60 seconds of expiration, the provider transparently rotates using the offline refresh token.
3. Anti-Loop & Idempotency Armor Dual-tier caching (in-memory LRU cache of 2,000 IDs + PostgreSQL snapshot comparison). Self-originating emails are immediately dropped to prevent infinite loops.
4. RFC Thread Preservation Inbound Gmail threadId and RFC headers (Message-ID, In-Reply-To, References) are tracked end-to-end so outbound replies stay grouped in the client's inbox.
